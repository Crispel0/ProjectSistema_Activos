Instalacion librerias

1)
ubicarse en la ruta base del entorno virtual "Projecto_software" dentro de la terminal de comando
2)Executar el siguiente comando pip install -r requirements.txt -t myenv\Lib\site-packages

NOTA
caso pida instalar Microsoft Build Version +14 el error  "error-microsoft-visual-c-14-0-or-greater-is-required"
en esta ruta url te explicaran como debes instalarlo
https://visualstudio.microsoft.com/visual-cpp-build-tools/

Inicializacion Projecto

1)ubicarse en la ruta base del entorno virtual "ProjectSistema_Activos-Prueba/ProjectSistema_Activos-Prueba" dentro de la terminal de comando
2) Executar el siguiente comando py manage.py runserver
3)ir a la ruta dentro del navegador 127.0.0.1:8000
